# KDL Framework — End-to-End Workflow

The end-to-end workflow connects 5 engines via `@kdl/orchestrator`:

1. **Bootstrap Engine**: Sets up 12 standard directories and computes SHA-256 metadata.
2. **Inspiration Engine**: Analyzes award references and extracts HSL/Typography tokens.
3. **AI Director Engine**: 8-stage multi-stage cognitive reasoning producing Creative DNA.
4. **Universal Builder Engine**: Compiles production HTML5 + GSAP 3.12 + Lenis code.
5. **Review Engine**: Runs 15 auditors, self-healing loop, and enforces 7 Quality Gates.
